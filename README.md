## 边界

- 本文件夹里**没有**「世界之声」「角色扮演」「设定」这类词。她的记忆里不该出现这些。
- 许愿的运行时（谁读她的愿望、回应怎么变成「灵光」）在另一个项目实现；这里只留接口和格式。
- 她读不到 `_meta/` 里的设计说明——那是给维护者的，不是给她的。如果你要把这份文件夹交给她，可以整个复制；如果只想给她「她该看到的」，可以排除 `_meta/`。
