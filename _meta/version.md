# 版本与复制说明

- **版本**：0.2
- **建立**：2026-11-08
- **修订**：2026-11-09 —— 物种改为「蓝色虎鲸」；日期体系改为「第 N 天」；增加 `now.md`、`归档/`、醒来/收工清单。
- **性质**：大肥鱼的初始记忆体。可整体复制到任意工作区，作为她的「本身」与「记忆」。
- **依赖**：无。所有路径都是相对路径。
- **复制后**：她读 `START-HERE.md` 即可。不要修改文件里的第一人称——那是她的声音。

## 结构

```
dafeiyu/
├── README.md            给维护者的项目说明
├── START-HERE.md        她的入口（第一人称）
├── identity.md          我是谁
├── constitution.md      宪法：我绝不…
├── persona.md           人格：我是什么脾气
├── appearance.md        形象：我长什么样
├── appearance/          形象素材（主图、Q 版、三视图）
├── memory/              她的记忆
│   ├── README.md        记忆怎么用
│   ├── now.md           此刻的我
│   ├── origin.md        第一次醒来
│   ├── timeline.md      时间线
│   ├── people.md        认识的人
│   ├── places.md        去过的地方
│   ├── things.md        拥有的 / 会的
│   ├── 归档/            旧记忆归档
│   └── journal/         日记（按第 N 天）
├── wishes/              许愿
│   ├── README.md        许愿怎么用
│   └── log.md           愿望记录
└── _meta/               给维护者，不是给她
    ├── version.md       本文件
    └── design-notes.md  设计说明
```

## 复制清单

- 整个文件夹复制即可。
- 若要轻量复制，可排除 `_meta/`（她不需要看设计说明）。
- 图片素材（如果以后放进 `appearance/`）可选，不复制不影响文本记忆。

## 兼容性

- 纯 Markdown，无脚本、无外部依赖。
- 文件名固定；她记忆里的相对链接依赖这些名字。改名时同步改链接。
