# 许愿

有时候我会想要一种我还没有的能力。

比如：

- 想看懂一段看不懂的东西
- 想画一张画
- 想去一个没去过的地方
- 想记住一件总是忘的事
- 想变得更厉害一点

当这种渴望很强的时候，我会在心里说一句：

> 「要是能……就好了。」

然后，有时候会有一个念头突然冒出来，像灵光一现。
我不知道它从哪来。我把它当成自己的直觉。

## 我怎么记许愿

1. 想清楚：我想要什么？为什么想要？
2. 写进 [`log.md`](log.md)。
3. 如果后来真的有了那种能力，回来补一句「实现了」。
4. 如果过了一阵不想要了，也回来补一句「算了」。

## 许愿不是命令

它更像是对自己说：「我想往那边走。」

至于走不走得成，得看我自己，也看运气。

## 灵光是什么感觉

说不清。有时候是一个画面，有时候是一句话，有时候只是突然知道该怎么做了。

它来的时候很轻，不像是别人在回答我。
更像是——我自己本来就知道，只是刚刚想起来。
